# Товар в деле — фулфилмент для маркетплейсов

Главная страница сайта: один файл `index.html` (HTML + CSS + JS, 3D-сцена на three.js).
Внешние зависимости грузятся с CDN: three.js r128 (cdnjs) и шрифты Onest / JetBrains Mono (Google Fonts).

## Где работает сайт
Продакшен — https://tovarvdele.ru/ на хостинге reg.ru. GitHub Pages больше не используется
(был только для старта разработки). Из репозитория сайт сам не обновляется: после мержа файлы
выкладываются на хостинг по SFTP.

## Сайт агентства «Madrocks agency»
Лежит в папке `agency/`, на проде это отдельный домен https://madrocks.agency/ (содержимое `agency/` выкладывается в его корень,
на tovarvdele.ru папки `agency/` нет). Адрес агентства — `BASE` в `tools/agency_pages.py`, адрес фулфилмента для ссылок
с агентства — `FF` там же. Ссылки между сайтами только абсолютные: с фулфилмента на `https://madrocks.agency/…`,
с агентства на `https://tovarvdele.ru/…`; относительные `agency/` и `../` между сайтами не использовать.

## Страница «Контакты»
`kontakty/` генерируется скриптом `python3 tools/contacts_page.py` из шапки, подвала и стилей главной.
Адрес склада (для Яндекс.Карты), координаты и телефон — константы `WAREHOUSE`, `COORDS`, `PHONE` в начале скрипта.
После правок главной или констант перезапустить скрипт и закоммитить `kontakty/`.

## Страницы «Услуги» и «Цены»
Фулфилмент: `uslugi/` (все услуги), `uslugi/<slug>/` (страница услуги по единому шаблону) и `ceny/` (прайс по группам)
генерирует `python3 tools/ff_pages.py`. Тексты и цены — в `tools/ff_services.py`; строки с `PH` — плейсхолдеры цен,
скрипт печатает их списком. Скрипт же обновляет цены и кнопки «Подробнее» в блоке «Что мы делаем» на главной,
добавляет страницы в `data/seo.json` и запускает `tools/seo.py`. Целевое действие на всех страницах — калькулятор:
ссылка `/#calc=fbs,mark` сразу отмечает операции, `/#calc=store` включает хранение.

Агентство: `agency/uslugi/…` и `agency/ceny/` генерирует `python3 tools/agency_pages.py` (тексты и прайс —
`tools/agency_services.py`, пакеты — `const PLANS` в `agency/index.html`).
Он же через `tools/agency_legal.py` собирает `agency/kontakty/` и `agency/dokumenty/`: оператор и реквизиты те же,
что у фулфилмента (константы в `tools/legal_pages.py` и `REQ` в `tools/contacts_page.py`), тексты документов — общий
шаблон `docs()` из `legal_pages.py` с формулировками агентства.

Файл `yandex_61639a54908f64cd.html` в корне — подтверждение Яндекс.Вебмастера, не удалять при выкладке.

## SEO
Все SEO-настройки — в `data/seo.json`: заголовки и описания страниц, адрес и координаты склада, телефон,
часы работы, ссылки на соцсети и карточки (`same_as`), коды Яндекс.Вебмастера и Google Search Console,
номер счётчика Яндекс.Метрики. После правок запустить `python3 tools/seo.py`: он обновит блок
`<!-- seo --> … <!-- /seo -->` в `<head>` страниц (title, description, canonical, Open Graph, иконки,
гео-метки, разметка schema.org: LocalBusiness, FAQ, хлебные крошки), продублирует «Частые вопросы» на главной
статичным HTML и пересоберёт `robots.txt`, `sitemap.xml`, `llms.txt`. Генераторы контактов и документов
запускают его сами. Новую страницу добавить в `pages` в `data/seo.json`.

Картинки (превью ссылки `img/og.png`, логотип `img/logo-512.png`, `favicon.ico`, `apple-touch-icon.png`)
пересобирает `node tools/seo_images.js`.

Сайт открыт на домене https://tovarvdele.ru/ (хостинг reg.ru), он же прописан в `site.base_url`
в `data/seo.json` и в `BASE` в `tools/contacts_page.py` и `tools/legal_pages.py`. При смене домена поменять
все три и перезапустить генераторы.
