# Письмо с заявкой из калькулятора

Сайт статический, поэтому письмо отправляет [EmailJS](https://www.emailjs.com/) прямо из браузера (бесплатно до 200 писем в месяц).

1. Зарегистрироваться в EmailJS, в **Email Services** подключить почту, с которой будут уходить письма (Gmail, Яндекс, Mail.ru или SMTP). Запомнить **Service ID**.
2. В **Email Templates** создать шаблон:
   - **Subject:** `Заявка на расчёт: {{total}} · {{name}}`
   - **To Email:** адрес менеджера, куда приходят заявки
   - **Reply To:** `{{email}}` (ответ на письмо уйдёт клиенту)
   - **Content:** переключить на «Edit Content → Code» и вставить целиком `calc-request.html`.
   Запомнить **Template ID**.
3. В **Account → General** скопировать **Public Key**; в **Account → Security** добавить домен сайта в разрешённые.
4. В `index.html` заполнить `const LEAD={service:'…',template:'…',key:'…'}`.

Пока ключи пустые, форма работает в демо-режиме: показывает «Расчёт у менеджера», а данные заявки пишет только в консоль браузера.

Переменные шаблона: `name`, `phone`, `phone_link`, `email`, `total`, `per_unit`, `discount`, `units`, `ops`, `lines_html` (строки расчёта, вставляется как HTML: `{{{lines_html}}}`), `lines_text`, `sent_at`, `page`, `consent` (когда и в какой редакции клиент дал согласие на обработку ПДн; письма с этой строкой хранить как подтверждение согласия).

## Заявка с сайта агентства (`agency/`)

Форма «Обсудить проект» на сайте агентства работает так же. Можно использовать тот же Service ID и Public Key, но нужен отдельный шаблон:
- **Subject:** `Заявка в агентство: {{topic}} · {{name}}`
- **To Email:** адрес, куда приходят заявки агентства
- **Reply To:** `{{email}}`
- **Content:** целиком `agency-request.html`.

Ключи вписать в `agency/index.html` в `const LEAD={service:'…',template:'…',key:'…'}`. Пока они пустые, форма работает в демо-режиме.

Переменные шаблона: `name`, `phone`, `phone_link`, `email`, `topic`, `services`, `services_html` (`{{{services_html}}}`), `shop`, `shop_html` (`{{{shop_html}}}`), `sent_at`, `page`, `consent` (согласие на обработку ПДн с датой и редакцией).

Открыть форму с другой страницы: ссылка на `https://madrocks.agency/#lead` или `https://madrocks.agency/#lead=Тема|Услуга,Услуга` (услуги — подписи чипов в форме).

## С 30.10.2026 основной канал — Telegram
Заявки сначала уходят в Telegram через `api/lead.php` (см. README в корне). EmailJS — запасной канал: срабатывает, только если эндпоинт не ответил `ok`, и только когда заполнены ключи в `const LEAD`. Без ключей запасного канала нет, а демо-режим убран.
